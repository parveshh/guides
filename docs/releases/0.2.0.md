# Guides 0.2.0 preview — CLI and agent skill

Control Guides directly from the terminal, or use the included `$guides` skill for CLI and computer-use workflows. This release includes the app and launcher, so no source checkout or Xcode is needed.

## Download and install

Choose **Guides-0.2.0-macOS-universal.zip** from the release assets. It contains **Guides.app**, the **guides** launcher, **skills/guides**, and **INSTALL.txt**. GitHub's source-code archives contain source only.

- Requires **macOS 14 or later**.
- Includes Apple Silicon (`arm64`) and Intel (`x86_64`) code; runtime checks cover Apple Silicon only.
- **Ad hoc signed; not Developer ID signed or Apple notarized.**

Quit an older copy after saving any layouts you want to keep, drag Guides.app to Applications, then open it. Measurements and calibration start fresh after quitting. Guides has a ruler menu bar icon and no Dock icon.

macOS may block the first launch. If you trust this download, try opening it once, then use **System Settings → Privacy & Security → Open Anyway** and confirm **Open**. [Apple explains this process](https://support.apple.com/en-us/102445). The app and package do not change security settings or remove quarantine; a managed Mac may not allow an exception.

## New in 0.2.0

- Direct commands for status/displays, overlay tools, exact guide/gap/Area geometry, selection, calibration/units, formatted reads, measurement undo/redo/delete/clear, pin and hide.
- JSON replies for scripts and agents; CSS, Tailwind and token-variable reads use the existing explicit-calibration and token-match rules.
- A standalone `guides` launcher and a self-contained `$guides` skill covering CLI and native computer-use workflows.
- Measurement commands preserve active pointer gestures by rejecting edits until the drag finishes or is cancelled. Transport waits are bounded; after a timeout, inspect status before retrying a mutation.

The local command channel is available to processes in the same login session. It has no network listener, capture, arbitrary file/selector execution or permission-request commands. Existing optional Accessibility and Screen Recording tools remain UI-only. No new app permission is required.

## Try the CLI

From the unzipped download folder:

```sh
./guides launch
./guides status
./guides show guides
./guides gap vertical 300 364
./guides read
./guides pin
```

Retry read-only `status` briefly after a cold launch if needed. This example places a 64-screen-point width at supplied coordinates; it does not detect an element or inspect CSS. Use the actual view scale with `calibrate PERCENT` before design pixels, rem or code output. An agent's sandbox may need its normal command-approval path for local Mach messaging.

For optional installation on PATH and skill installation, read **INSTALL.txt** inside the ZIP. Computer use requires desktop-control tools in the agent session. See the [CLI reference](https://github.com/parveshh/guides/blob/v0.2.0/skills/guides/references/cli.md) and [usage guide](https://github.com/parveshh/guides/blob/v0.2.0/docs/USAGE.md).

## Verify and preview limits

Download **Guides-0.2.0-SHA256SUMS.txt** beside the app ZIP, then run:

```sh
shasum -a 256 -c Guides-0.2.0-SHA256SUMS.txt
```

The result should end in **OK**. This checks integrity and does not replace Developer ID signing or notarization.

Intel runtime, older supported macOS versions, physical input across displays and full VoiceOver remain unverified. The prior locked-screen visual-check limit remains documented; native command/gesture checks do not establish final screen alignment. There is no automatic updater. See [validation and remaining checks](https://github.com/parveshh/guides/blob/v0.2.0/TESTING.md).
