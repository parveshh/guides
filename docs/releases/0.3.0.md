# Guides 0.3.0 preview — Guide Groups

Measure a Figma frame and its browser implementation side by side, even when they use different zoom levels. Each Guide Group has its own guides, Area, scale and undo history. The updated Codex skill uses the group’s ID to read either pane while you work.

## Download and try it

Download **Guides-0.3.0-macOS-universal.zip** from the release assets. The ZIP includes **Guides.app**, the standalone **guides** launcher, the updated **skills/guides** folder and **INSTALL.txt**.

1. Save any layouts you want to keep, quit the older Guides app, and drag the new **Guides.app** into **Applications**. Open it and choose **Edit Guides** from the ruler icon in the menu bar.
2. Choose **+ Group**, draw around the Figma content, name it **Figma**, and enter its effective scale. Repeat for **Implementation**. If either scale is uncertain, leave it blank and use **Set scale → Known size** with a known span in that pane.
3. Click inside the Figma group and pull guides from the rulers to measure a gap. Repeat in the implementation group. With confirmed scales of 200% and 100%, a 48-screen-point Figma gap and a 24-screen-point implementation gap both read **24px**.
4. To try the agent workflow, install or update the skill following **INSTALL.txt**. With both panes visible, ask a computer-use-enabled agent: “Use $guides to compare the card in Figma with its browser implementation. Check its insets and gaps and report the differences.”

## Compatibility and verification

Requires **macOS 14 or later**. The universal binary includes Apple Silicon and Intel code. It is **ad hoc signed**, without Developer ID signing or Apple notarization. If macOS blocks the first open and you trust the download, try opening the app once, then use **System Settings → Privacy & Security → Open Anyway**. [Apple first-open guidance](https://support.apple.com/en-us/102445)

To verify the download, place **Guides-0.3.0-SHA256SUMS.txt** next to the ZIP and run `shasum -a 256 -c Guides-0.3.0-SHA256SUMS.txt`. The result should end in **OK**.

Runtime checks covered Apple Silicon. The two-pane native fixture uses synthetic cards. A live Figma/browser pair, Intel runtime and older supported macOS versions remain unverified. [Verification details](https://github.com/parveshh/guides/blob/v0.3.0/TESTING.md)
