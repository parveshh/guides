# Guides 0.1.0 preview

The first downloadable preview of Guides, a macOS menu bar app for measuring and marking visible layouts.

## Download

Choose **Guides-0.1.0-macOS-universal.zip** from this release's assets. It contains the app; the GitHub source-code ZIP and tarball contain source only.

- Requires **macOS 14 or later**.
- Includes Apple Silicon (`arm64`) and Intel (`x86_64`) code.
- No Xcode installation is needed to run it.
- This is an **ad hoc signed preview, without Developer ID signing or Apple notarization**.

## Install and open

1. Unzip the app and drag **Guides.app** to **Applications**.
2. Quit any older copy, then open the installed app. Look for the ruler icon in the menu bar; there is no Dock icon.
3. macOS may block the first launch. If you trust this download, try opening it once, then choose **System Settings → Privacy & Security → Open Anyway** and confirm **Open**. [Apple explains this process here](https://support.apple.com/en-us/102445). A managed Mac may not allow an exception.
4. Press **Control–Option–G** or choose **Edit Guides** to start measuring.

The app does not change system security settings. Normal measurement needs no privacy permission. Accessibility is optional for Resize Window; Screen Recording is optional for the live Corner Magnifier and is requested only from its explicit button.

## Included

- Manual guides and Area measurements, including a manually fitted corner radius.
- Selected guide pairs highlighted in cyan, with measurement labels you can drag along the other axis.
- The new context bar for Guides, Area and Annotate, plus Pin & work.
- Explicit calibration for design pixels and rem, CSS/Tailwind copying and spacing-token matches.
- Annotations, spotlights, grids, local reference images, saved layouts, project profiles and breakpoint markers.
- Local image-dimension inspection and optional app-window resizing.

Measurements describe visible distances, not inspected CSS or Figma properties. See the [usage guide and examples](https://github.com/parveshh/guides/blob/v0.1.0/docs/USAGE.md).

## Verify the download

Download **Guides-0.1.0-SHA256SUMS.txt** beside the app ZIP, then run this in the folder containing both files:

```sh
shasum -a 256 -c Guides-0.1.0-SHA256SUMS.txt
```

The output should end in **OK**. This checks file integrity; the checksum does not replace Developer ID signing or notarization.

## Preview limits

The build includes both architectures, but runtime checks cover only the current Apple Silicon Mac. Intel, macOS 14 and other older supported systems, physical input across displays and full VoiceOver operation still need manual testing. There is no automatic updater. Quit and replace the app to update; current measurements start fresh after quitting.

See [validation and remaining checks](https://github.com/parveshh/guides/blob/v0.1.0/TESTING.md).
